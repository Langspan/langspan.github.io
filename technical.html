Before you
install.

Is this for teams or solo builders?+

Both. LangSpan is built around teams working on connected parts of a project. A solo developer running several agents has the same need for shared awareness and is a useful place to start.

Do I need to change my agent setup?+

Keep your existing sessions. Project hooks add briefings and edit checks to supported operations. CLI and MCP access let other tools inspect and contribute to the work records. The optional dashboard is read-only.

Does LangSpan replace Git worktrees?+

No. Worktrees isolate checkout contents. LangSpan adds related work context and local coordination where supported; combined checks can expose semantic conflicts that a clean Git merge misses.

What happens when an edit is refused?+

Supported overlapping or stale edits may be refused. The agent can reread, retry or choose another task. This may interrupt some sessions; LangSpan does not claim a general wait queue for edit holds. Remote awareness and supported argument-count break alerts are advisory. A practitioner's report on queueing versus refusals describes why this is an important trade-off.

Does it stop every conflicting write?+

No. Coordination covers supported operations while their holds are active. Writes outside hooks, some shell rewrites, and edits approved after a hold expires can still proceed. LangSpan complements your agent’s own permissions and your team’s checks and review.

What leaves my machine?+

Local coordination stays in local state. Remote sharing is opt-in through your Git remote. It shares work metadata such as branch and file activity; source content is excluded and task text needs its own opt-in. Remote work informs briefings and never denies a local edit. These limits describe LangSpan's publications, not your coding agent provider's data handling.

What can I use today?+

The latest stable release is available for Linux and macOS, ARM64 and x86-64. See release notes. Claude Code and Codex have retained native-session evidence. Cursor support is built from its documentation and has not yet run on a real host. Antigravity was corrected after one real run; a repeat run is pending. See what’s verified for each host. Homebrew and Windows support aren’t available yet.

Are these recordings of real agents?+

The hero and interactive walkthrough are authored illustrations of supported workflows. They run locally in your browser, without an agent or daemon. Real-session observations and remaining gaps are recorded in the implementation evidence.
