# Product-led page v2

## Direction

The owner approved the in-chat wireframe after referencing Ripple Treasury AI
Agents, Claude product overview, Lovable website builder, xAI and Perplexity
Computer. Use the existing LangSpan brand and motion assets. Borrow progressive
discovery, outcome-first sections, scenario exploration and a concise
three-step story; do not copy another product's visual identity.

The page order is hero, before/after comparison, three-step explanation,
interactive explorer, technical depth, genuine dashboard evidence, optional
launch film, download/setup, FAQ and mission close. Preserve `#demo`,
`#team-story`, `#coordination-demo`, `#workflow`, `#evidence`, `#film`,
`#start` and `#mission`. Capability tabs have named deep links.

## Evidence boundaries

Use the original Stageshow edit coordination scene as one of six capabilities.
Five new scenes use the same vendored Stage, Window, Prompt and Code primitives
with a three-beat 10.8-second host-controlled story. They are explicitly authored
illustrations, not real host transcripts or executable UI. Local checks only
cover supported operations and active holds, remote awareness is advisory and
opt-in, commit attribution can be ambiguous, integration requires matching
successful evidence and explicit apply. The per-tab source links point to
retained native-host or scripted scenario evidence. Keep the actual released
dashboard crops unmodified and labelled. Do not imply measured team outcomes.

## Motion

The hero remains the existing Living Canvas-informed illustration. On the new
explorer, autoplay once on view, pause when offscreen, hidden, or globally
paused, use 270 ms ease-out for the incoming state, 620 ms for metadata flow;
manual step selection is immediate. Reduced motion shows the final frame with
working steps. The three technical illustrations animate once on entry only
where a relationship or result is explained. No pretend cursor or decorative
loop. Use original approved brand tokens, no new runtime dependencies.

## Validation

The canonical scene definitions live in marketing/story.json, in
capabilityExplorer. Existing four-step Stageshow and ChanMeng narrative and
published film assets are unchanged. Build the same existing JS bundle using
demo-src/build.mjs. Verify the generated asset and its hash, all six tabs
(including direct links, keyboard roving, replay, reduced motion, no JS),
the genuine dashboard proof, actual video playback, setup, links and WCAG
scans at 1440, 1280, 768, 390 and 358 px. Inspect the artifacts before merge.
Do not treat Hallmark or Impeccable advisory findings as a certification.
