Keep warm paper, ink and coral, approved logos, actual Stageshow component kit, Living Canvas-informed motion, existing ChanMeng variants and actual released product evidence. ## Grounding

- CooperBench: https://arxiv.org/abs/2601.13295 — 30% lower average success for cooperating agents relative to completing tasks individually.
- ParallACT: https://arxiv.org/abs/2611.00314 — 62% to 16% in the specific contradictory-task Claude Code / Opus 4.8 comparison.
- Anthropic, Worse Together: https://alignment.anthropic.com/2026/worse-together/ — four simulated environments, group performance worse with separate agents than with a coordinator.
- Michele Matozza's November 14 account: https://dev.to/mfmatozza/when-every-teammate-runs-a-coding-agent-the-agents-cant-see-each-other-1on1 — clean merge can hide an incompatible renamed export/new caller.
- The November 20 queue/refusal account: https://dev.to/mfmatozza/why-my-coding-agent-coordinator-never-refuses-an-edit-kpn — different samples, directional evidence, not a controlled comparison. The current product's local edit refusals are not a queue.

The 5+5 configuration comes from the owner's described workflow. It is an illustration of a topology, not a ten-session LangSpan verification, benchmark or capacity claim. Each cloud environment has its own coordinator; opt-in Git publications carry metadata rather than source contents. The semantic baseline is reproduced using real Git and Node; neither an agent nor LangSpan runs in that example. The briefing-assisted repair is an authored hypothetical, not observed behavior. Source-change alerts are bounded to supported argument-count mismatches, not guaranteed cross-file semantic enforcement. Retained two-machine evidence proves briefing delivery, not changed agent behavior.
